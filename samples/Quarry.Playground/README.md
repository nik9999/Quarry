# Quarry.Playground

Консольный демонстрационный стенд и песочница для интерактивной проверки возможностей RAG-системы **Quarry**.

---

## Что демонстрирует стенд

1. **Инициализация локальной ONNX модели**:
   Загрузка квантованной модели `multilingual-e5-small` (112 МБ) и токенизатора SentencePiece без обращения к внешним API.
2. **Инициализация векторной базы данных SQLite-vec**:
   Создание таблицы `chunks`, виртуальной таблицы `vec_chunks` с метрикой `cosine` и включением режима WAL.
3. **Пакетная индексация документов**:
   Чанкинг и векторизация тестового набора русскоязычных и англоязычных документов (ИТ, финансы, HR) с сохранением метаданных.
4. **Семантический поиск (KNN)**:
   Выполнение поисковых запросов («Как настроить гибридный поиск?», «Каков бюджет отдела маркетинга?») с замером задержки инференса и ранжированием по косинусному сходству.
5. **Pre-filtering по метаданным**:
   Поиск с ограничением выборки по категории (`category = 'finance'`) через встроенный JSON-индекс SQLite.

---

## Запуск стенда

```bash
dotnet run --project samples/Quarry.Playground
```
